# Gather Here

A wedding-weekend product concept for one couple to manage invitations, replies, practical details, and the guest site’s style.

This repository contains a **fictional, browser-only prototype** and proposed requirements. It does not provide real guest accounts, private access, shared storage, or a live RSVP service. Gather Here is a working name.

## Prototype

The selected experience combines a personal guest programme with an organizer workspace. The example wedding is entirely fictional. Changes to replies stay in the current tab; style choices stay in the current browser.

The hosted walkthrough is being prepared. It will explain the plan and provide guided entry points into the prototype.
